🧩 Option B — Use overflow-clip

If your reason for using overflow-hidden is purely visual overflow trimming, not functional clipping, then use the newer CSS property:

#features {
  overflow: clip;
}


or in Tailwind (if you have a plugin or custom class):

<section className="overflow-clip">


🟢 overflow: clip hides overflow without creating a new containing block,
so sticky still works!
(But note: browser support — Chrome 109+, Firefox 120+, Safari 17.4+ — which is fine for modern users.)
